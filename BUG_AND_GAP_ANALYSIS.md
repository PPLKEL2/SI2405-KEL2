## 2. Temuan Risiko & Konflik Repositori Git (`SI2405-KEL2`)

Hasil pemeriksaan langsung terhadap seluruh *branch* lokal dan jarak jauh mengungkap 4 kondisi kritis yang wajib ditangani sebelum mulai mengintegrasikan kode aplikasi:

| ID | Keparahan | Cabang / Berkas Terdampak | Temuan Kondisi Repositori | Mitigasi Wajib |
| :--- | :---: | :--- | :--- | :--- |
| **`REPO-01`** | **Kritis** | `Raihan_Branch` (`2666be0`) vs `origin/main` (`291e2d6`) | `Raihan_Branch` bercabang dari komit awal `803232c` dan belum di-*merge* (`PR #1`), sementara `origin/main` sudah menerima `PR #2, #3, #4, #5`. Menimpa `main` dari `Raihan_Branch` akan **menghapus 4 berkas PBI anggota lain** (`01 - Kalkulator Biaya BBM.txt`, `03 - Manajemen Katalog Kendaraan Listrik.txt`, `KEL2-69.txt`, `Peta Interaktif Fasilitas EV.txt`). | Dilarang melakukan *force-push* atau *reset*. Integrasikan secara aditif (*union merge*) sehingga ke-7 berkas `.txt` dari seluruh anggota tetap utuh di *root*. |
| **`REPO-02`** | **Tinggi** | `NamaAnggota.txt` lintas seluruh *branch* | Pada `origin/main` (`commit 93070df`), pengeditan `NamaAnggota.txt` tidak sengaja menimpa baris `Najwa Aulia - 102042430015`, dan nama `Arsyad` hanya tercatat di `Raihan_Branch:NamaAnggota.txt`. Terdapat konflik *merge* langsung antara `origin/main` dan `Raihan_Branch` pada berkas ini. | Gabungkan isi `NamaAnggota.txt` secara lengkap memuat ke-6 anggota beserta seluruh NIM yang sudah tercatat tanpa menghapus kontribusi siapa pun. |
| **`REPO-03`** | **Sedang** | `origin/Salsa_Branch` (`97d8c56`) vs `origin/Salsa_branch` (`7e5a9ac`) | Terdapat dua *branch* di GitHub yang hanya berbeda kapitalisasi huruf `B`/`b`. Pada Windows (NTFS *case-insensitive*), perintah `git fetch origin` gagal keluar dengan `exit code 1` karena tabrakan nama ref lokal. | Kedua komit sudah masuk dalam riwayat `origin/main` (`291e2d6`). Gunakan `git fetch origin main` secara spesifik saat menarik pembaruan, dan koordinasikan penghapusan ref duplikat yang sudah *merged* di GitHub UI dengan pemilik *branch*. |
| **`REPO-04`** | **Tinggi** | Seluruh *branch* (`main, Raihan, Najwa, Fitri, Fadli, Salsa`) | **0% kode aplikasi tersedia di Git.** Seluruh *branch* hanya berisi berkas `.txt` identitas/judul PBI. Seluruh kode UI saat ini hanya berada pada hasil ekstraksi *prototype* Figma Make. | Bangun proyek aplikasi di dalam folder terpisah (`client/`, `server/`, `shared/`) dari basis `origin/main` sehingga berkas `.txt` anggota kelompok tidak pernah tersentuh atau terhapus. |
